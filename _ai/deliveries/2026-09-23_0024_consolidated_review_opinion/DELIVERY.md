- **规范达成**：
  1. **零括号硬指标**：全词库 `zh_name` 彻底消除了任何英文字符括号 `()` 或中括号 `[]`，100% 杜绝 `[中文]` 这种占位符。
  2. **生活化通俗听感**：非音乐小白无需任何乐理即可直观理解（如 `[Verse]` 解构为“在讲事情的一段”，`[Chorus]` 解构为“最想被人记住的那几句”，`[Drop]` 解构为“音乐突然静止然后猛地炸开”）。
  3. **去冗余化**：全词库彻底清理了任何歌手名字、账号信息、过时模型代号。
  4. **配套专家评审表**：已同步导出 `Music_Expert_Review_Sheet.md` 与带 UTF-8 BOM（Excel 打开不乱码）的 `Music_Expert_Review_Sheet.csv`。

### 模块二：“做第一首歌”抽屉向导

- **规范达成**：
  1. 抽屉顶部常驻 6 步新手做歌指南，引导非音乐小白快速成歌。
  2. **复制按钮数量严格受控**：

     - 第 2 步（段落怎么排）：0 复制按钮

     - 第 6 步（怎么接着往下做）：0 复制按钮

### 模块三：“上英下中”双行紧凑排版策略（用户明确要求）
- **文件**：`src/ui/styles.css`、`src/core/injector.js`
- **规范达成**：
  1. 针对顶部 `+ Audio`、`+ Voice`、`+ Inspo` 紧凑并排按钮组，启用 `.suno-copilot-stacked-btn` 与 `.suno-copilot-nav-zh.stacked`。
  2. **上面一行**显示原生英文（如 `+ Audio` / `+ Voice` / `+ Inspo`）；
  3. **下面一行**显示紧凑中文小字（`添加音频` / `加入一段声音` / `从歌单里找感觉`）；
  4. **完全在按钮内部自闭环换行**，严禁向外部 3 列网格容器插入任何兄弟节点，100% 确保 3 个按钮原位稳固，彻底根除了横向撑爆容器、把同排按钮挤出视口的隐患。

### 模块四：音乐风味恢复与 Token Masking 防机翻覆盖机制
- **文件**：`src/core/injector.js`、`scripts/build.js`、`dist/chrome-extension/background.js`
- **规范达成**：
  1. **专业音乐风味**：
     - `four-on-the-floor` ➔ `四四拍正拍律动`
     - `fingerstyle` ➔ `细腻指弹`
     - `electric guitar` ➔ `电吉他清音与扫弦`
     - `choir` ➔ `唱诗班合唱`
     - `deep house` ➔ `深邃内敛的浩室舞曲`
  2. **连词智能拆解（Conjunction Splitting）**：
     - 不仅按逗号 `,`、分号 `;` 分段，同时识别 ` and `、` with `、` feat. `、` & ` 等复合连词。
     - 像 `tight four-on-the-floor groove and surprise kazoo` 会自然拆为两段，前半句立即由本地词库命中，同步立刻呈现「紧凑利落的四四拍正拍律动」，绝不留白。
  3. **占位符遮罩（Token Masking）**：
     - 针对无法拆分的复合句，在投送谷歌前将本地专业词戴上代号面具（如 `SCTERM0X`）。
     - 谷歌只翻译生词部分，返回后插件无损反解还原为「四四拍正拍律动」，谷歌从始至终无法输出“地板上的四个”。
  4. **逆向机翻纠偏（MISTRANSLATION_FIXES）**：
     - 内置常见机翻硬伤字典，三重防护防止任何漏网。
